## Field Note

Golden Software Grapher is easier to trust when the chart stays smaller than the worksheet it came from. A named session shows which plot is active, the pins show which series you will draw today, and the closing note tells the next person which 2D 3D plots drive the graph layout. That record is short on purpose: not a copy of every column, only the path back to the chart that is still open.

The same loop fits a student series, a client page, or a computer shared by two analysts. Open the last Golden Software Grapher session, confirm one layout, and leave the labeled chart easier to find than you found it. Worksheets stay where they are. Golden Software Grapher only holds the worksheet charts, the summary, and the handoff.

## One Real Pass

Pick a worksheet that already has a name: a small time series, a scatter set, or a short contour. Open it in Golden Software Grapher, keep only those columns on the board, and read one labeled chart you can point to. A pass is done when that chart is tied to the graph layout and the unused rows are no longer in the way. Golden Software Grapher does not need a full rebuild of the worksheet before it is useful.

If the pass feels crowded, the page is too wide. Drop anything that belongs to a different plot and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first column to the last legend, with the summary still matching the 2D 3D plots on the board.
